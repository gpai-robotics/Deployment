\bigskip

\noindent\textbf{Summary}

The latest policy is fully plug-compatible with the baseline policy. Both policies use the same deployment interface, including the observation vector, history buffer, action representation, joint ordering, action scaling, control frequency, and PD controller. The only substantive difference is the learned network weights, which result from training on different tasks. Consequently, if the latest policy behaves differently while using the same deployment pipeline, the cause is expected to be the policy itself (e.g., terrain or stair generalization) rather than any mismatch in the deployment interface.
